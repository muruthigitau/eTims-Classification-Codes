# KRA Item Classification

**KRA Item Classification** refers to the categorization of items based on their tax treatment as defined by the Kenya Revenue Authority (KRA). These classifications are crucial for determining applicable tax rates, exemptions, and compliance requirements for different types of goods and services.

## Classification Hierarchy

The classification uses four levels:

| Level | Description |
| :--- | :--- |
| 1 | Top-level category (e.g., VAT Act) |
| 2 | Major grouping (e.g., Goods, Services) |
| 3 | Sub-category (e.g., Exempt Goods, Zero Rated Goods) |
| 4 | Specific item or tariff-level entry |
